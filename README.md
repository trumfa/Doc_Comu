# doc_comu

Base documental del Comú d'Encamp: normativa (lleis, ordinacions, reglaments, decrets), actes del Consell de Comú, polítiques internes i informació de funcionament, convertida a Markdown amb metadades per poder-la consultar de manera ràpida i fiable (també per agents d'IA).

- **Per consultar**: comenceu per [`INDEX.md`](INDEX.md). Els agents, per [`AGENTS.md`](AGENTS.md).
- **Per saber què és vigent**: [`VIGENCIA.md`](VIGENCIA.md).
- **Convencions** (metadades, taxonomia, vigència, noms, procés de curació): carpeta [`convencions/`](convencions/).
- **Eina de pujada i conversió**: el projecte `pdf-to-md` (Vercel) envia els documents convertits a `inbox/`.

Estructura: `docs/` (consulta) · `arxiu/` (històric) · `originals/` (PDF) · `inbox/` (pendent) · `scripts/` (procés).
